# Browser access failures

Recommend enabling Chrome Remote Debugging only after verifying that its switch is disabled on the target machine. `browser_consent_required`, `consumer_profile_endpoint_requires_grant`, or an approval popup that cannot be found or accessed mean connection approval is blocked, not that Remote Debugging is disabled. Report the exact approval/access blocker and target machine; if the popup is inaccessible or the remedy is unknown, say so rather than inventing a fix.
