# Triage media

An attachment matters when its contents can change where work belongs, its scope or price, approval, execution, or completion.

Inspect files by type: view images and screenshots, transcribe or analyze audio, look at only the needed parts of video, extract text from documents. Use filename, MIME type, context, and the source ID or link to judge relevance.

Downloads are scratch files under `~/.cache/fulldev/work-triage/`. Keep media under your home directory, not `/tmp`, because the PDF and image tools reject files there. WhatsApp media is already on disk at the path in the item. These paths are not permanent references. Inspect the original when you can. Make a smaller derivative or selected frames only when a tool needs them. A derivative never replaces the original, and a small preview cannot prove details you cannot read in it.

When media defines a requirement, decision, acceptance condition, blocker, handoff, or proof of completion, keep the full-resolution original. Add it, or a permanent URL to it, to the right Company, Project, or Task `Resources` as `work-management` describes, and keep the source reference in the Task Timeline when the file is Task evidence. Leave incidental media at its Gmail, Slack, WhatsApp, meeting, or file source when that source can be reopened.

Report a blocker when a needed file cannot be inspected or kept well enough for the decision. An unavailable duplicate attachment does not block an outcome that other evidence supports.
