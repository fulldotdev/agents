# Moneybird document layout

Use the agreed scope and billing basis. Prices come from `commercial-scoping`, new wording from `customer-communication`.

Prefer a few clear lines. A normal line has a bold heading and one specific paragraph that says what the work is and how it is billed. Add `Kenmerken:` or `Inbegrepen:` bullets only when they make the line clearer.

Put one-off work first and monthly packages last. Use `Eenmalige werkzaamheden` and `Doorlopende service` as category labels when they fit.

On an invoice with several workstreams, name each one with its agreed basis, such as `9 uur per week` or `4 uur per twee weken`. Keep fixed billing descriptions unchanged.

Follow the quantity, period, and price conventions in [operations.md](operations.md). After writing, check headings, line order, optional status, and amounts. The layout must keep the agreed difference between included, optional, one-off, and recurring work visible.
