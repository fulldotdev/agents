# Channel rules

Apply only the channel used by the customer conversation.

## WhatsApp

- Keep it ultra-short and conversational.
- Use fragments when natural: "Staat online", "is gefixt", "kan ik fixen", "begin volgende week".
- Use Dutch shorthand when it fits Sil: `ff`, `t`, `idd`, `sws`, `isgoed`, `rdy`.
- Use emojis sparingly: ✅, 👍🏻, 👌🏻, 💪🏻.
- Include the preview URL in the same message whenever calling something a preview.

## Email

- Open with `Hey Naam`, `Hi Naam`, or `Hoi Naam`.
- Explain a preview, document, request, or decision before providing its link or details.
- Close with the concrete ask or default: "Laat me weten...", "Hoor graag of dat klopt", or "Mocht ik voor [datum] niks horen, dan..."
- Keep replies unsigned. Rely on the mailbox's configured signature when needed. Add a written sign-off only when the user asks for one.

## Slack

- Match the workspace language. Code-switch only when the thread already does.
- Put the version or status first, followed by any bullets and the owner or check request.
- Use direct pings when a specific person's action is needed.
- Typical shared-channel updates include "fixed in 2.18.2 ✅", "on it", and "preview is now pushed as 2.18.0 ✅".
