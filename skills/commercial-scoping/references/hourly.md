# Hourly work

Use the agreed hourly rate and billing period. Distinguish estimated hours, an approved limit and actual billable hours; an estimate is not automatically a fixed price or spending approval.

Show hours and rate when explaining time-based pricing. Keep the explanation tied to the work requested; do not force category prices or a separate internal/customer document pair.

Check whether the work is covered by an existing package or agreement before adding it. If expected effort exceeds an agreed limit, explain the extra work and decision needed rather than silently increasing the commitment.

Use actual hours only from the requested, verified source. Access Productive only when Sil explicitly asks for it.
